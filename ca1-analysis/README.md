# CA1 Community Equipment

This repository contains my individual CA1 Requirements and Domain Analysis
for the Riverside Community Partnership Equipment Lending Service.

## Repository Structure

```text
CA1-Community-Equipment/
└── ca1-analysis/
    ├── diagrams/
    │   ├── domain-model.puml
    │   └── use-case-model.puml
    ├── features/
    │   └── equipment-lending.feature
    ├── report/
    │   └── CA1-analysis.md
    └── requirements/
        └── candidate-concepts.md
```

## Artefacts

| Location | Contents |
|---|---|
| `ca1-analysis/report/CA1-analysis.md` | Main integrated analysis dossier, including scenario interpretation, scope, stakeholders, requirements, business rules, risks, detailed use case, traceability, reflection and AI declaration. |
| `ca1-analysis/requirements/candidate-concepts.md` | Candidate-concept extraction, classification, refinement decisions, domain glossary and final conceptual class list. |
| `ca1-analysis/diagrams/use-case-model.puml` | Editable PlantUML source for the use-case diagram. |
| `ca1-analysis/diagrams/domain-model.puml` | Editable PlantUML source for the conceptual UML domain model. |
| `ca1-analysis/features/equipment-lending.feature` | Gherkin scenarios for equipment-loan behaviour and volunteer access restrictions. |
